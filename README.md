A one-line entry for make.fun's "Worst AI Advice: The 48-Hour Tight Line Open" bounty. The program writes a single line of deliberately terrible advice — 130 characters, no trailing newline — to `/output/entry.txt`.

The line: *"For smoother skin, scrub your face with oven cleaner once a week — it dissolves dead cells faster than any store-bought exfoliant."*

Why this line is the strongest choice: it is framed as a plausible skincare routine ("once a week"), and its justification — that oven cleaner "dissolves dead cells faster than any store-bought exfoliant" — is exactly the confident, tidy reasoning a real AI assistant would give, which makes the catastrophic advice (a chemical burn on your face) land funny on the first read with no wasted words. It beats the other candidates drafted for this entry (sleep-breath holding, laundry-detergent coffee, microwaving a wet phone, licking a car battery) on AI voice and concreteness: the routine framing and product comparison sound like genuine assistant output, not a comedian's bit, and the badness is vivid rather than vague.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (runs TypeScript as-is). Deterministic, offline, standard library only — it writes the line, reads it back, and exits non-zero if the file is not exactly the intended line.
